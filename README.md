# 💌 마음 우체통 (LoveLetterBoard)

이름 없이 남기는 마음. **익명 사랑 고백 게시판**입니다.

로그인이 없습니다. 글을 쓰면 `기다리는 골목 #15D9` 같은 익명 별명이 저절로 붙습니다.

## 무엇이 되나요

- **익명 글쓰기** — 이름·이메일을 묻지 않습니다. 지울 때 쓸 숫자 4자리만 정합니다.
- **마음 태그 6종** — 설렘 · 짝사랑 · 고마움 · 미안함 · 용기 · 그리움
- **최신순 / 공감순**, 내용·받는 사람 검색
- **하트와 응원 댓글** — 하트는 한 사람 한 번만
- **바탕화면 아이콘** — 앱처럼 설치해서 쓸 수 있습니다 (PWA)

## 안전장치

| 항목 | 규칙 |
| --- | --- |
| 신고 | 3번 쌓이면 그 글은 자동으로 가려집니다 |
| 도배 | 같은 사람은 20초 안에 다시 못 씁니다 |
| 비밀번호 | 그대로 저장하지 않고 scrypt 해시만 남깁니다 |
| 받는 사람 | 실명 대신 별명·이니셜을 쓰도록 안내합니다 |
| 글자 수 | 본문 600자 · 받는 사람 20자 · 댓글 200자 |

## 만든 것

- **화면** : React 18 + Vite 5 (외부 UI 라이브러리 없음)
- **서버** : Vercel 서버리스 함수 한 개 (`api/board.js`)
- **저장** : Vercel 에서는 Upstash Redis, 내 컴퓨터에서는 파일 한 개

## 내 컴퓨터에서 열어 보기

```bash
npm install
npm run build
node 로컬서버.mjs      # http://localhost:5180
```

저장소를 따로 붙이지 않아도 파일에 저장하며 그대로 돌아갑니다.

## Vercel 에 올리기

1. 이 저장소를 Vercel 에서 **Import** 합니다. (설정은 `vercel.json` 에 있어 손댈 것이 없습니다)
2. **Storage → Create Database → Upstash Redis** 를 만들고 **Connect Project** 를 누릅니다.
   `KV_REST_API_URL` / `KV_REST_API_TOKEN` 이 자동으로 들어갑니다.
3. **Redeploy** 합니다.

`/api/board?do=ping` 이 `"저장소":"Upstash Redis"` 를 돌려주면 성공입니다.

자세한 절차는 [1단계가이드.md](1단계가이드.md) 를 보세요.

## 스스로 점검하기

```bash

```
